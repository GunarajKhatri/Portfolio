01. about

I'm a software engineer from Nepal who enjoys owning a feature from the database schema all the way to the pixels. I wrote my first Laravel apps back in 2018 and haven't stopped building since.

I studied Electronics Engineering at Pulchowk Campus. Along the way I shipped REST APIs, real-time chat systems and e-commerce platforms, and went deeper into AI and networking: a ResNet + LSTM deepfake detector and a deep-reinforcement-learning SDN load balancer for my final year project.

Now I'm a Backend Engineer at Rara Labs, building production services in Go with gRPC and PostgreSQL. I like clear API contracts, sensible schemas, and code the next person can pick up easily.
